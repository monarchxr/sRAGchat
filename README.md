# sRAGchat
sRAGchat is a RAG chatbot that lets you search, download and
chat with arXiv research papers locally on your machine.

## Requirements
Python 3.10+ \
Ollama installed and running

## Setup
git clone https://github.com/monarchxr/sRAGchat \
cd sRAGchat \
pip install -r requirements.txt \
ollama pull llama3.2

## Usage
streamlit run app.py
